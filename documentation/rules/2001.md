### 2001 - DifferentAnyOf

**Description**: Checks whether the list of schemas referenced by an `anyOf` has changed from the previous specification. The schemas referenced in both versions are then compared.

**Cause**: This is considered a breaking change.

**Example**: The `Cat` schema is added to the `anyOf` of the `pet` property in the new version.

Old specification
```json5
{
  "type": "object",
  "properties": {
    "pet": {
      "anyOf": [
        { "$ref": "#/components/schemas/Dog" }
      ]
    }
  }
}
```

New specification
```json5
{
  "type": "object",
  "properties": {
    "pet": {
      "anyOf": [
        { "$ref": "#/components/schemas/Dog" },
        { "$ref": "#/components/schemas/Cat" }
      ]
    }
  }
}
```

Note: an `anyOf` (or `oneOf`) with a single schema and a `{"type": "null"}` schema only makes that schema nullable (OpenAPI 3.1):
it is reported as a nullable change (rule 2000), not by this rule.
